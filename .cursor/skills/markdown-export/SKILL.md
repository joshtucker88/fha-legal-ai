# Markdown Export

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify target audience, heading structure, links, tables, and code block needs.
3. Normalize headings, lists, citations, and file references for readability.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return clean Markdown with stable structure and minimal formatting noise.
- Keep findings concise, traceable, and separated from speculation.
