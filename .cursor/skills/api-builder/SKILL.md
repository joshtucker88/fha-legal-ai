# API Builder

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Define contract, authentication, validation, error cases, and data ownership.
3. Follow existing framework patterns and add focused tests for observable behavior.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return endpoint behavior, schema, examples, and verification commands.
- Keep findings concise, traceable, and separated from speculation.
