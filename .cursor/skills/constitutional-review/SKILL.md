# Constitutional Review

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify the constitutional provision, actor, right, burden, and standard of review.
3. Apply doctrine to facts while separating precedent, argument, and uncertainty.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return issue summaries, governing tests, factual predicates, and litigation risks.
- Keep findings concise, traceable, and separated from speculation.
