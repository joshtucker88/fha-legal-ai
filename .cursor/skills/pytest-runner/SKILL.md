# Pytest Runner

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Select the narrowest useful pytest command before broad test runs.
3. Read failures for behavior, fixture, environment, and assertion signals.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return failing tests, likely cause, applied fix or next test, and rerun result.
- Keep findings concise, traceable, and separated from speculation.
