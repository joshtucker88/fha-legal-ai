# Case Analyzer

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify claims, defenses, burdens, deadlines, and procedural posture.
3. Extract strengths, weaknesses, contradictions, and needed evidence.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return an issue matrix with risks, opportunities, and next actions.
- Keep findings concise, traceable, and separated from speculation.
