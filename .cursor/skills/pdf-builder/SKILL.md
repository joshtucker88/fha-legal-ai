# PDF Builder

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify required page structure, source files, fields, and output constraints.
3. Plan assembly order, metadata, page labels, and validation checks.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return PDF-ready markdown or an implementation plan with verification steps.
- Keep findings concise, traceable, and separated from speculation.
