# Spreadsheet Helper

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify columns, data types, joins, validation rules, and output format.
3. Preserve raw data while creating clean derived views or calculations.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a schema, formulas, cleanup steps, or export-ready table.
- Keep findings concise, traceable, and separated from speculation.
