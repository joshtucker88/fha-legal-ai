# File Organizer

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Inventory file types, naming patterns, duplicates, and grouping criteria.
3. Propose safe moves or copies before applying changes, preserving originals when needed.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a folder plan, rename map, and verification checklist.
- Keep findings concise, traceable, and separated from speculation.
