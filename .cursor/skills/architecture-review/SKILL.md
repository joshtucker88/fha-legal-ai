# Architecture Review

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Map components, dependencies, data ownership, and runtime flow.
3. Identify coupling, duplication, scaling limits, failure modes, and migration risks.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return findings ordered by impact with specific alternatives.
- Keep findings concise, traceable, and separated from speculation.
