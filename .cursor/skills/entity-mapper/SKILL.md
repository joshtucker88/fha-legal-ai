# Entity Mapper

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Normalize entity names, identifiers, dates, locations, and source references.
3. Separate confirmed relationships from inferred or weak associations.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return an entity map, relationship list, and confidence labels.
- Keep findings concise, traceable, and separated from speculation.
