# Python Debugger

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Reproduce the failure or inspect the traceback, inputs, environment, and recent changes.
3. Localize the defect with minimal experiments before changing code.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return root cause, fix plan, verification command, and residual risks.
- Keep findings concise, traceable, and separated from speculation.
