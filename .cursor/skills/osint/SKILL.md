# OSINT

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Define the lawful objective, scope, constraints, and permitted sources.
3. Collect public-source leads while preserving provenance and avoiding unsupported escalation.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return sourced leads, confidence levels, and ethical or legal constraints.
- Keep findings concise, traceable, and separated from speculation.
