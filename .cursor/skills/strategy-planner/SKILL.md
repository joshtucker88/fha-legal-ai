# Strategy Planner

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Define objectives, constraints, deadlines, leverage, and decision points.
3. Compare options by risk, cost, evidence needs, timing, and reversibility.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a phased action plan with dependencies and decision gates.
- Keep findings concise, traceable, and separated from speculation.
