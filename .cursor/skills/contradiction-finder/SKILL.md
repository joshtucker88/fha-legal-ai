# Contradiction Finder

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Extract comparable claims, dates, actors, quantities, and source anchors.
3. Classify conflicts as direct contradictions, omissions, ambiguity, or timing differences.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a contradiction matrix with source references and follow-up questions.
- Keep findings concise, traceable, and separated from speculation.
