# Federal Rules

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify the governing federal rule, local rule, deadline, and procedural posture.
3. Check triggering events, timing, required content, service, and filing constraints.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return rule text summaries, deadlines, procedural steps, and caveats.
- Keep findings concise, traceable, and separated from speculation.
