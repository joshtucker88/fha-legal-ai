# Web Investigator

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Start from authoritative or primary sources before secondary commentary.
3. Record source URLs, timestamps, claims, and confidence for each finding.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a sourced findings brief with unresolved questions.
- Keep findings concise, traceable, and separated from speculation.
