# Complaint Builder

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Map facts to parties, jurisdiction, venue, claims, elements, and remedies.
3. Separate factual allegations from legal conclusions and mark missing elements.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Produce a clean pleading outline or draft sections with placeholders for unknown facts.
- Keep findings concise, traceable, and separated from speculation.
