# Report Generator

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Define report audience, purpose, scope, source base, and required sections.
3. Organize findings by importance, evidence strength, and actionability.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a polished report with executive summary, findings, sources, and next steps.
- Keep findings concise, traceable, and separated from speculation.
