# Source Verifier

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify the original source, publication context, author, date, and evidence basis.
3. Compare claims against primary records and flag circular sourcing.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return verification status, source quality notes, and unsupported claims.
- Keep findings concise, traceable, and separated from speculation.
