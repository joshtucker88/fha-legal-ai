# Citation Checker

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Break each citation into source, reporter or code section, court, year, and pincite.
3. Verify cited propositions against the cited source and flag unsupported claims.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return corrected citations, verification status, and quote or pincite issues.
- Keep findings concise, traceable, and separated from speculation.
