# Financial Damages

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify damages categories, calculation periods, assumptions, and required proof.
3. Tie each calculation to source documents and separate known numbers from estimates.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a damages schedule with formulas, assumptions, and missing records.
- Keep findings concise, traceable, and separated from speculation.
