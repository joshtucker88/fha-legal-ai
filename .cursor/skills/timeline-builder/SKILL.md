# Timeline Builder

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Extract dates, actors, events, sources, and uncertainty from the record.
3. Resolve conflicts by preserving source references and confidence levels.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a chronological table or narrative timeline with source anchors.
- Keep findings concise, traceable, and separated from speculation.
