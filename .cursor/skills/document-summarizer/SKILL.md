# Document Summarizer

## Quick Start
1. Clarify the request, available inputs, constraints, and success criteria.
2. Identify document type, purpose, audience, and required level of detail.
3. Extract key facts, holdings, decisions, dates, parties, and action items.
4. Return the result in the requested format with assumptions and open risks.

## Output Guidance
- Return a concise summary with source anchors, caveats, and notable omissions.
- Keep findings concise, traceable, and separated from speculation.
